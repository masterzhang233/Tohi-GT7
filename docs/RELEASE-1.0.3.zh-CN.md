# Tohi-GT7 1.0.3 — 原生 PSSR 接口、4K DLSS 重建与 NVIDIA 2X 插帧

> [!IMPORTANT]
> **本版本仅支持 NVIDIA GeForce RTX 40／50 系列显卡。** 其他显卡不在本版支持范围内。
> 本次游戏内实测使用 **RTX 5080**，不代表已逐一测试所有 RTX 40／50 系列型号。

基于 Tohi-GT7 1.0.2，默认启用 **1920×1080 → 3840×2160 DLSS 超分重建 + NVIDIA 2X 帧生成**，并选择性移植 KytyPS5 2026-11-25 主线版本中的关键更改。版本号为 **1.0.3**，发布标签为 **`v1.0.3`**。

## 更新内容

- **原生 PSSR 接口接入 DLSS**：接收游戏原生 Psml/PSSR 请求及真实颜色、深度、运动矢量、抖动和重置参数，使用 PC 上的 NVIDIA DLSS 后端重建 4K 画面。这里的“PSSR”指游戏接口与渲染路径，**不代表运行 Sony 的 PSSR 神经网络模型**。
- **固定 1080p → 4K**：默认使用专用原生渲染配置，让已验证的主场景以 1920×1080 输入、3840×2160 输出。保留对游戏版本、原始补丁字节和资源尺寸的检查；不修改磁盘上的游戏文件。
- **NVIDIA 2X 帧生成**：每个原始帧请求生成一帧，经 Vulkan/Streamline 呈现。本版只提供固定 **2X**，不提供 3X、4X 或动态多帧生成。DLSS 的 preset M 是超分模型请求，与插帧倍率无关。
- **减少插帧中断**：改进相机投影与实际深度范围的验证、同一组相机输入的复用，以及超分源图和最终无 HUD 画面的生命周期管理。继续验证深度、运动矢量、相机和 HUD；不满足条件时暂停插帧并呈现原始帧。
- **读回与资源一致性修复**：CPU 读取 GPU 更新的数据时等待读回真正发布，避免把仍在下载的旧镜像当作干净数据；保留资源别名、外部写入及同帧一致性检查。
- **启动器界面优化**：保留原有 GT7 赛车背景、暗色界面和红色操作按钮，调整顶部区域高度、间距与信息层级，补充清晰的启动／运行状态。默认勾选项统一标为 **“4K + NVIDIA 2X”**，可手动关闭；启动前检查所需运行库是否齐全。

## 验证范围与限制

- 在 Windows、RTX 5080、GT7 **PPSA01317 01.710.000** 上完成纽北实际驾驶验证。运行记录确认原生 1080p → 4K DLSS 与 NVIDIA 生成帧活动，正常退出。用户在指定对比中反馈插帧中断“明显减少或没有中断”。
- 该功能候选的 **21 项专门回归全部通过**。完整测试为 **104／109 通过**，其余 5 项与改动前基线的失败签名一致；不能表述为全套测试通过。
- 部分 HUD、菜单或未验证的场景切换仍可能使插帧暂停。本版不承诺所有赛道、车型、视角都连续 2X，也不将这次驾驶观察当作显示帧率或画质的完整基准测试。
- **游戏内 FPS 仍统计原始游戏帧，不包含生成帧**。即使插帧正在工作，该数字也不会因此翻倍。2X 同样不表示游戏逻辑、输入采样或 CPU 模拟速度翻倍。
- 1080p 输入降低部分主场景渲染负担，但 4K 重建、后处理、呈现和模拟器 CPU 工作仍有开销，不能保证比原生 4K 达到某个固定帧率提升。

## 使用与升级

退出旧程序后完整解压，运行 **`launcher.exe`** 或 **`Start-GT7-Desktop.cmd`**，添加自己的兼容 GT7 目录后启动。默认勾选 **“4K + NVIDIA 2X”**，已配置原生 1080p → 4K 和 NVIDIA 2X；普通游玩不需要开发脚本、F9/F10 捕获或手动设置环境变量。

游戏内使用**性能／帧率模式**。本版不建议开启光线追踪（RT）。保持正常日志设置；首次使用新着色器缓存时会重新编译部分内容，编译阶段可能出现卡顿。

覆盖升级时保留原有 `_DownloadData`、`_SaveData`、`_Trophies` 及配置文件，并完整复制随包运行库、`fonts` 和 `licenses`。发行包不包含游戏文件、个人存档或开发日志。需要简体中文时，将游戏配置中的“主机语言”设为“简体中文”；Noto Sans CJK SC 字体及开放许可证继续随包提供。

技术细节见[原生 PSSR/DLSS 说明](NATIVE-PSSR-DLSS.md)和[NVIDIA 帧生成说明](GT7-NVIDIA-FRAME-GENERATION.md)。早期版本的 FSR 插帧和实验记录保留在历史文档中，不代表本版的默认配置。
