# Tohi-GT7 1.0.4 — 原生 PSSR 2K → 4K · 无插帧版

> [!IMPORTANT]
> **本版本仅支持 NVIDIA GeForce RTX 40／50 系列显卡。** 其他显卡不在本版支持范围内。
> 游戏内实测使用 **RTX 5080**，不代表已逐一测试所有 RTX 40／50 系列型号。

本版以画质与实际渲染的连贯性为优先，默认使用 **2560×1440（2K）→ 3840×2160（4K）** 超分重建，移除 NVIDIA FG／MFG、FSR 插帧以及新增的 30 FPS 限制。版本号为 **1.0.4**，发布标签为 **`v1.0.4`**。

## 更新内容

- **原生 PSSR 接口，2K 输入重建 4K**：接收游戏原生 Psml／PSSR 请求及实际颜色、深度、运动矢量、抖动和重置参数，在 PC 上使用 **NVIDIA DLSS Super Resolution，preset M** 重建画面。这里的 PSSR 指游戏接口和渲染路径，**不代表运行 Sony 的 PSSR 神经网络模型**。相较此前的 1080p 输入，1440p 提供更多原始像素用于重建，同时也需要更多渲染工作。
- **不使用任何帧生成**：正式包不含 Streamline、DLSS-G、Reflex 或 FidelityFX 插帧运行库，NVIDIA 和 FSR 插帧均在构建时关闭。每个呈现的游戏帧来自实际渲染后的超分重建，不插入生成帧；这不是原生 4K 渲染，也不是未经重建的原始图像。
- **取消额外限帧**：撤下测试中的 30 FPS 基础帧限制，不再运行该测试的限帧／插帧组合。游戏自己的帧循环、模拟速度和原有呈现机制仍然生效，不承诺任意场景都达到 60 FPS。
- **保留 GT7 启动器风格**：沿用赛车背景、暗色界面和红色操作按钮，默认选项更新为 2K → 4K 重建，启动前仅检查超分所需运行库。采用 **全屏 + Mailbox**；4K 是重建目标，物理显示尺寸跟随桌面分辨率。
- **保留版本及资源检查**：固定 1440p 配置检查兼容游戏映像、补丁摘要和原始字节，不改写磁盘上的游戏文件。运行时继续使用真实资源及有效矩形，不把高分辨率资源伪标为低分辨率输入。

本版不引入插帧带来的额外等待或生成帧延迟，但尚未测量端到端输入延迟。画面质量和流畅度仍取决于场景、主机性能、驱动及模拟器工作负载，不宣称画质绝对最佳、延迟最低或完全无卡顿。

## KytyPS5 主线基础

继续保留 1.0.3 从 **KytyPS5 2026-11-25 主线**选择性移植的 8 项图形同步、内存、等待事件和着色器缓存改进。本次没有把整个上游主线重新合并，也不将这些已有改进重复列为新移植。具体提交和适配范围见 [1.0.3 说明](RELEASE-1.0.3.zh-CN.md#kytyps5-11-月-25-日主线同步范围)。

## 实机验证与限制

- **本版所依据的 1440p 无插帧测试基准**在 Windows、RTX 5080、GT7 **PPSA01317 01.710.000** 上完成两轮驾驶验证，两次均正常退出，进程返回值为 0。这是此前测试候选的实机结果，不表示最终以 FG 编译关闭方式构建的 1.0.4 发行包已重复完成这两轮驾驶。
- 两轮最后记录的 PSSR 请求／DLSS 评估计数分别为 **38,400／38,400**、**9,600／9,600**，线性缩放回退均为 **0**；共 86 条有界 PSSR 状态样本的输入／输出尺寸始终为 **2560×1440 → 3840×2160**。
- 用户反馈：**慢动作消失，卡顿大幅减少，仍有轻微卡顿**。运行记录未发现 Vulkan device lost 或 DLSS 失败。上述数据确认已观察场景的超分路径，不是显示 FPS、逐帧耗时或延迟基准，也不代表所有赛道、视角和车型均已测试。
- 首次遇到新着色器或缓存失效时仍可能编译并产生卡顿；这两轮没有逐帧性能采样，不能把残余卡顿直接归因于着色器编译或某一模块。

## 使用与升级

退出旧程序，将 **`Tohi-GT7-1.0.4-Windows-x64.zip`** 完整解压到新的目录，再运行 **`launcher.exe`** 或 **`Start-GT7-Desktop.cmd`**。不要混入旧版本的插帧 DLL。保留并按原有位置迁移自己的 `_DownloadData`、`_SaveData`、`_Trophies` 和配置文件；发行包不包含游戏文件、个人存档或个人日志。

默认使用 2K → 4K 重建。普通游玩不需要测试脚本、F9／F10 捕获或手动设置环境变量。正常 API 日志为 **Silent**，不自动开启性能采样、画面捕获或定时退出；必要的启动和有界状态信息仍可能记录。

游戏内使用**性能／帧率模式**，本版不建议开启光线追踪（RT）。简体中文显示继续使用随包附带的 Noto Sans CJK SC 字体及开放许可证；需要时将游戏配置中的“主机语言”设为“简体中文”。

下载包同时提供 **`.sha256`** 校验文件和 **`release-manifest.json`**。技术细节见[原生 PSSR／DLSS 说明](NATIVE-PSSR-DLSS.md)。早期 NVIDIA／FSR 插帧文档只用于历史和开发参考，不是 1.0.4 的功能或启动说明。
